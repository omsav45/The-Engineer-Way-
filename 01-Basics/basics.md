# Python Basics

## 🔢 Data Types
Python has four primary data types:
1. **Numeric:** `int` (integers), `complex` (complex numbers).
2. **Text:** `str` (Strings - anything inside single or double quotes).
3. **Boolean:** `bool` (True or False).
4. **Floating Point:** `float` (Decimal numbers).

## 📦 Variables
A variable is a name given to a memory location that stores data.
**Naming Rules:**
- Cannot start with a number.
- Cannot contain spaces.
- Cannot be a Python keyword (like `if`, `while`, `class`).

## ➗ Basic Operators
- **Arithmetic:** `+`, `-`, `*`, `/`, `%` (modulo), `**` (exponent), `//` (floor division).
