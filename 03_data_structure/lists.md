# Python Lists

A **List** is an ordered collection of items that is **changeable (mutable)** and allows duplicate values.

## 🛠️ List Operations
- **Indexing:** Access items starting from `0`. Use `-1` to access the last item.
- **Adding:** Use `.append(item)` to add an element to the end.
- **Removing:** Use `.remove(item)` to delete a specific element.
- **Updating:** Use `list[index] = new_value` to change an item.
